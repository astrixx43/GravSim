
# GravSim

1. A non-trivial gravity simulator with relativistic characteristics.

2. This simulator implements:

3. Relativistic elastic collisions

4. Relativistic non-elastic

5. Time-dialation

6. Your choice of Wave-Like Gravitons, Particle-Like Gravitons, and Classical Newtonian gravity

7. Relativistic Doppler Effect

8. EIH method of gravitation simulation (coming soon)

9. And JSON support for setting up your own custom states(coming soon)

  
  

## The Goal

The goal of this simulator was to make a computationally efficient and visually appealing demonstration of the wonders and quirks of relativistic physics. 
Simply said, the goal is to play around…

  
  

## How To Run

You may adjust your simulation and visualization constants or variables at the very top of the GravSim.c file.

Once Values have been set, run the makefile and launch the executable.

This is the Windows implementation, so you will require MSYS2 to compile using the makefile and the make command (since it's compiling with GCC and GDB for debugging)
